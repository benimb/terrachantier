# TerraChantier

Application de suivi de chantier de la suite TerraSuite (TERRAFORM) : comptes-rendus de visite, OPR et levée des réserves, photos prises sur le téléphone et localisées sur les plans de niveaux (PDF).

- Application web installable (PWA) : fonctionne hors réseau, s'installe depuis le navigateur du téléphone.
- Données sur l'appareil (IndexedDB), synchronisées entre appareils par Supabase quand le réseau est là.
- Aucune donnée de chantier n'est stockée dans ce dépôt : il ne contient que le code de l'application.

Adresse : https://benimb.github.io/terrachantier/
